# Project-K — GCP Firewall Port Reference
# Use this when creating VPC firewall rules and Load Balancer health checks.
# Last updated: matches k8s/base config (GKE production) + docker-compose (local dev).
#
# IMPORTANT
# - Open PUBLIC rules only on the correct Load Balancer / target tags — NOT on every VM.
# - Use 0.0.0.0/0 for sources only on internet-facing media endpoints (or restrict by region if needed).
# - INTERNAL ports must stay cluster-private (never expose to the internet).
#
# =============================================================================
# GKE PRODUCTION — OPEN TO INTERNET (required for WebRTC to work)
# =============================================================================
#
# Apply these to:
#   • GKE Gateway / Application Load Balancer  (HTTPS app + Janus WSS proxy)
#   • coturn NLB external IP                   (k8s/overlays/gke/coturn-nlb.yaml)
#   • Janus media NLB external IP              (k8s/base/janus.yaml → janus-media-nlb)
#
# --- 1) Web app + API + Janus signaling (GKE Gateway) ------------------------
# Service: k8s/base/gateway/gateway.yaml, httproutes.yaml
# Browser traffic hits your domain; Gateway routes to control-plane + janus WS.
#
PROTOCOL   PORT(S)     DIRECTION   PURPOSE
--------   ---------   ---------   ---------------------------------------------
TCP        443         INBOUND     HTTPS — web UI, REST API (/api/*), WSS Janus (/janus)
TCP        80          INBOUND     HTTP — optional redirect to HTTPS only (do not serve app on plain HTTP in prod)
#
# --- 2) coturn STUN/TURN (dedicated NLB) -------------------------------------
# Service: coturn-media LoadBalancer
# Config:  k8s/base/config/coturn-configmap.yaml (min-port / max-port)
# Set TURN_HOST in app-configmap to the coturn NLB external IP.
#
PROTOCOL   PORT(S)           DIRECTION   PURPOSE
--------   ----------------  ---------   ---------------------------------------------
UDP        3478              INBOUND     STUN + TURN signaling (primary)
TCP        3478              INBOUND     TURN signaling fallback (TCP)
UDP        20000-29000       INBOUND     TURN relay media (allocated on demand per session)
#
# Optional (enable when TURN_USE_TLS=true in app-configmap):
# TCP        5349              INBOUND     TURN over TLS (turns:)
#
# --- 3) Janus SFU — RTP media (dedicated NLB) --------------------------------
# Service: janus-media-nlb LoadBalancer
# Config:  JANUS_RTP_PORT_RANGE in k8s/base/config/app-configmap.yaml
#
PROTOCOL   PORT(S)           DIRECTION   PURPOSE
--------   ----------------  ---------   ---------------------------------------------
UDP        10000-11000       INBOUND     Janus VideoRoom RTP/WebRTC media
#
# Webinar / Streaming plugin rtp_forward (if using fan-out on same node):
UDP        15000-15200       INBOUND     Janus Streaming plugin RTP (optional; only if webinar fan-out enabled)
#
# NOTE: Janus WebSocket signaling (8188) is NOT opened directly on the NLB.
#       Browsers use wss://YOUR_DOMAIN/janus via the GKE Gateway on port 443.
#

# =============================================================================
# GCP VPC FIREWALL — SUGGESTED RULE GROUPS (copy/paste reference)
# =============================================================================
#
# Rule name: kzys-allow-gateway-https
#   Target:   GKE Gateway / node pool tag (or use GKE-managed firewall rules)
#   Source:   0.0.0.0/0
#   Allow:    tcp:443, tcp:80
#
# Rule name: kzys-allow-coturn
#   Target:   coturn NLB backend / nodes with coturn pods
#   Source:   0.0.0.0/0
#   Allow:    udp:3478, tcp:3478, udp:20000-29000
#
# Rule name: kzys-allow-janus-media
#   Target:   Janus NLB backend / janus StatefulSet nodes
#   Source:   0.0.0.0/0
#   Allow:    udp:10000-11000
#   Optional: udp:15000-15200
