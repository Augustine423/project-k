# Project-K port reference — LiveKit stack
#
# Public (internet-facing):
#   • GKE Gateway / ALB  — HTTPS app + LiveKit WSS proxy (/livekit)
#   • LiveKit media NLB  — UDP WebRTC (production overlay)
#
# --- 1) Web app + API + LiveKit signaling (GKE Gateway) --------------------
#
# Browser traffic hits your domain; Gateway routes to control-plane + LiveKit WS.
#
# Protocol   Port    Direction   Purpose
# TCP        443     INBOUND     HTTPS — web UI, REST API (/api/*), WSS LiveKit (/livekit)
#
# --- 2) TURN / coturn --------------------------------------------------------
#
# TCP/UDP    3478    INBOUND     TURN relay (NAT traversal fallback)
# UDP        20000-20200         TURN relay allocation range (dev compose)
#
# --- 3) LiveKit SFU — WebRTC media -------------------------------------------
#
# UDP        50000-50100         LiveKit RTP/WebRTC media (dev compose)
# TCP        7881                LiveKit RTC TCP fallback
#
# NOTE: LiveKit WebSocket signaling (7880) is NOT opened directly in production.
#       Browsers use wss://YOUR_DOMAIN/livekit via the GKE Gateway on port 443.
#
# --- 4) Internal cluster only (never public) ---------------------------------
#
# TCP        4000        control-plane        REST + room WebSocket
# TCP        6379        redis                Room state / pub-sub
# TCP        7880        livekit              WS signaling (cluster; public uses Gateway :443)
#
# --- 5) Local docker compose (localhost) -------------------------------------
#
# TCP        4000        server               Control plane API
# TCP        5173        web                  Vite dev UI (HTTPS)
# TCP        7880        livekit              LiveKit WS signaling
# TCP        7881        livekit              LiveKit RTC TCP
# UDP        50000-50100 livekit              LiveKit media
# TCP/UDP    3478        coturn               TURN
# UDP        20000-20200 coturn               TURN relay range
# TCP        6379        redis                Redis
#
# Checklist (production):
# [ ] GCP firewall allows UDP 50000-50100 to LiveKit NLB
# [ ] LiveKit public URL uses wss://APP_HOST/livekit (port 443)
# [ ] Redis and control-plane :4000 are NOT reachable from internet
